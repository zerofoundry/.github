ZeroFoundry is where I release the tools I build for digital art work: small, native programs that run on your own machine and stay out of your way. It's a one-person studio.

### ZeroConverter

A file converter for Windows that works the way you always hoped renaming would. Change `clip.mp4` to `clip.mp3` in File Explorer and the file actually converts. Images, audio, game textures and video, all offline. Free and open source.
